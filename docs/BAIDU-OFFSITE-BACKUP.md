本地程序边界：

- 只接受项目外云备份目录中合法命名的 `.cjbackup`，先执行既有解密/格式验证；原始数据库、配置、密钥、整个目录不能上传。
- 凭据默认在本机 `%LOCALAPPDATA%/CampusJobsRadar/baidu-oauth.json`，可通过 `BAIDU_OFFSITE_CREDENTIAL_FILE` 指向项目外文件；此轮没有创建真实凭据文件。它是百度应用授权，不是数据库解密密钥。凭据不得放到Git、托管部署包或网盘。
- 每次使用新文件名，预上传和创建均设冲突即失败，不覆盖或删除远端旧副本；暂未启用远端自动清理。原先手动副本保留原位置，未来接口上传使用应用授权目录 `/apps/{appname}`，不是自动迁移旧目录。
- 校验分片返回的MD5，核对创建结果的路径、大小和文件编号，拒绝不可信上传主机或重定向。返回 `verification=download-required`：本地SHA-256和云端MD5记录不能代替独立下载、解密和恢复复验。
