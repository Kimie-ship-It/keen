# 云端采集器运行与安全交接方案

## 状态与结论

2026-10-01：P03.2完成平台无关的交接方案整理，未创建托管资源、未购买服务、未上传密钥、未停止本机任务，也未启用云端采集。2026-10-02 用户明确当前采用本机采集，云端工作器只作为网站稳定运行后的可选升级，不阻塞本次上线；P03.2总项仍待未来确认平台、费用和实际交接条件，P03.3/P03.4未开始。

推荐采用**独立的、带持久磁盘的单实例工作器**运行采集程序，网站托管和采集工作器分开：

- 网站运行环境只提供学生查询、详情、收藏导出和管理接口，不运行采集器，不保存 SQLite。
- 采集工作器保存已播种的 SQLite、四校 JSON 快照、运行日志和本地备份目录，使用项目外的密钥存储。
- Supabase PostgreSQL 是网站查询及管理状态的线上数据库；采集工作器只同步五张采集表，不覆盖审核状态、审核审计、登录限速和来源下架状态。
- 工作器部署规模固定为 1，定时任务禁止重叠；在真正启用前必须完成可验证的跨进程/跨机器租约或数据库锁。

当前没有确认具体平台。Vercel 适合网站，不适合承载需要持久 SQLite 和采集快照的工作器；无持久磁盘的临时任务平台不能直接采用。平台、地区、费用、日志保留和持久磁盘能力须由用户确认后再创建。

## 数据与持久化边界

工作器持久卷至少包含以下目录，均不进入 Git 或公开上传：

| 内容 | 用途 | 丢失后的处理 |
| --- | --- | --- |
| `data/campus-jobs.db` | 采集基线和增量写入 | 从最近核验的 SQLite 步骤备份恢复，不能从空库启动 |
| `data/*-recruitments.json` | 四校排查快照 | 可由采集重建，但恢复前仍需保留数据库基线 |
| `data/logs/` | 采集、健康和脱敏故障记录 | 由平台日志或备份补查，不能把日志当数据库备份 |
| 项目外本地备份目录 | SQLite 与云端加密快照 | 从独立副本恢复，不能只依赖工作器磁盘 |
| 项目外百度授权文件 | 自动异地上传授权 | 无授权时必须保持上传关闭并报告失败 |

密钥与数据分离保存：`SUPABASE_BACKUP_KEY` 使用独立的密码保护密钥文件；百度授权文件只放在项目外的密钥目录；数据库密码、管理口令和恢复目标地址不写入代码、Git、备份文件或聊天。网站运行时不需要备份密钥、百度授权和 `SUPABASE_RESTORE_DB_URL`。

## 单执行器与交接门

交接期间必须按以下顺序操作，任何一步失败都停止，不自动覆盖任一数据库：

1. 暂停本机 `CampusJobsRadar-Daily` 的下一轮写入，并记录任务状态；当前本机任务在交接完成前仍是唯一采集执行器。
2. 等待正在运行的本机流程结束，确认四校结果、五表同步、备份和健康检查均有完整日志。
3. 使用同一时间点的 SQLite、四校快照和 Supabase 五表内容做基线核对；空库、旧库、编号不一致或字段差异均停止。
4. 将 SQLite、快照、项目外备份目录和授权文件安全放入工作器持久卷/密钥存储；不通过网站部署包传递。
5. 先以 `CAMPUS_CLOUD_COLLECTOR_ENABLED=0` 启动工作器，确认配置被读取但没有采集、同步或上传；再执行只读启动基线检查。
6. 验证平台只启动一个实例、定时任务不重叠，并完成可回收的租约/锁验证；当前 `collect:cloud` 的启动检查不是并发锁，不能跳过这一门。
7. 仅在 B02、P02、平台确认和安全交接全部通过后，关闭本机写入任务并由用户明确确认启用云端开关。启用后第一次运行必须保留完整日志和独立恢复证据。

回退时先停止云端工作器，再恢复本机任务；回退前重新比较五张采集表，并核对云端审核和来源下架状态，不得用旧 SQLite 直接重新公开已隐藏或已下架内容。

## 工作器配置白名单

真正部署时，工作器只需要以下配置；值应由平台密钥存储注入，不写入镜像或仓库：

- `CAMPUS_CLOUD_COLLECTOR_ENABLED`：交接前为 `0`，验收后才允许改为 `1`。
- `CAMPUS_JOBS_STORAGE=supabase`、严格 TLS 和正式 `SUPABASE_DB_URL`。
- `CAMPUS_JOBS_DB`：持久卷内已播种 SQLite 的绝对路径。
- `SUPABASE_BACKUP_KEY`：已有 64 位十六进制备份密钥。
- `BAIDU_OFFSITE_ENABLED=1` 与项目外百度授权文件：只有 B02真实上传、下载恢复和失败提醒验收后才配置。

工作器不注入 `ADMIN_TOKEN`、`SUPABASE_RESTORE_DB_URL`、`PRIVACY_CONTACT_EMAIL` 或暂缓的飞书配置。数据库连接必须使用证书校验，禁止用不安全 TLS 例外通过启动检查。
